# Product Hunt launch kit

**Tagline (60 char):** Stay awake, stay green — with proof, not promises

**Description:**
EspressoMacchiato is a menu bar keep-awake for macOS & Linux that actually
works with Teams/Slack presence: besides preventing sleep, it resets the OS
idle counter with invisible input events — and shows you the counter live,
so you see it working. Plus a full battery dashboard (health, cycles,
watts, 8h charts), call auto-detection, meeting-end timers, 25-minute
espresso focus shots, Raycast commands and a URL scheme for Shortcuts.
100% local, zero telemetry, open source (MIT).

**First comment (maker):**
Every keep-awake app I tried kept my Mac on… and Teams still went yellow
after 5 minutes, because presence clients read the OS *idle counter*, not
the sleep state. So I built the tool I wanted: two mechanisms (sleep
inhibition + invisible idle reset), a live counter that proves it's
working, and — since it sits in the menu bar all day anyway — a proper
battery dashboard. No accounts, no network
