Sleep inhibition alone isn't enough

Most keep-awake tools only stop sleep. Presence clients read the OS idle counter, which keeps climbing anyway — after ~5 minutes you go Away.

We reset the real counter

An invisible zero-delta pointer event resets the same counter Teams and Slack read. The cursor never moves; nothing reaches your apps.

Watch it work

The Idle Monitor shows the OS idle counter live — you see it climb and snap back to zero. No hoping.

An energy dashboard too

Battery health, cycles, temperature, watts, interactive history — all local, nothing persisted, nothing sent anywhere.
